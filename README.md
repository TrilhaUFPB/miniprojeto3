# Mini-Projeto 3

Essa é a etapa final das aulas. Encerramos o nosso conteudo com um projeto prático: uma rede social. O objetivo dessa aplicação é que vocês desenvolvam habilidades práticas acerca do mundo fullstack. Dessa forma, utilizaremos todo o conteudo aprendido nessa trilha prática de fullstack para implementar o front e o back.  

## Requisitos

- Login e Cadastro de usuario

- Autenticação e autorização de usuario

- Criar, Editar e excluir uma postagem

- Página unica com as postagens

- Like ou dislake por usuario nas postagens

- Listagem de like e dislake por postagem

## Objetivos

- Ideação e esboço do sistema

- Modelagem de dados

- Implementação do backend

- Implementação do frontend

## Exemplo

Esse repositorio é um exemplo de implementação e ideação acerca desses requisitos.

> [!TIP]
> É recomendavel que usem esse exemplo e repositorio apenas como uma base para desenvolver a sua propria rede social.

### Para executar

#### Front 

Necessário node.js instalado

```bash
cd front

npm i
npm run dev
```

Necessário python instalado

```bash
cd back
pip install -r requirements.txt

cd src
python -m fastapi dev 
```
